# Flow Matching and Diffusion Models 7-Stage Learning Project

This repository records my 7-stage study of Flow Matching, Diffusion Models, and FlowDCN reproduction.

## Goal

The goal is to build a solid theoretical and practical understanding of:

- Generative modeling as sampling
- ODE-based flow models
- SDE-based diffusion models
- Flow Matching
- Score Matching and DDPM
- Classifier-Free Guidance
- Latent Diffusion
- Discrete Diffusion
- FlowDCN reproduction and analysis
